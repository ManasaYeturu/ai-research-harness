# PostgreSQL

PostgreSQL is an open-source object-relational database management system.

It supports SQL and provides features for storing, querying, and managing structured data.

PostgreSQL supports tables, primary keys, foreign keys, constraints, indexes, views, functions, and transactions.

A primary key uniquely identifies each row in a table.

A foreign key establishes a relationship between a column in one table and a primary key or unique key in another table.

Indexes can improve query performance by allowing PostgreSQL to locate rows more efficiently.

Transactions allow multiple database operations to be executed as a single logical unit of work.

PostgreSQL is commonly used for web applications, backend systems, analytics applications, and enterprise software.
